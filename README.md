# Fault Prediction and Assistance (Automobile)

Web dashboard for an Arduino Uno vehicle monitor (DS18B20 temperature + battery voltage).
Runs in Chrome/Edge using the Web Serial API, with a built-in Fake Arduino mode for testing.

## Run
Serve the folder on localhost (e.g. VS Code Live Server, or python -m http.server 8000)
and open it in Chrome or Edge.
